# Vireon — AI Video Editor

Scaffold for an Electron + React + Vite + TypeScript + Tailwind desktop application.

Run locally:

1. Install dependencies: `npm install`
2. Start renderer dev server: `npm run dev:renderer`
3. Start Electron: `npm run dev:electron`

Or start both with: `npm run dev` (requires `concurrently`).
